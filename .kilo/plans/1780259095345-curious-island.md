# Plan: Bismillah Header Above Progress Ring

## Goal

Add a Bismillah + app title block (replicating the screenshot) above the progress ring in `DhikrCard`, visible on every card.

---

## What the image shows

1. **Top line** — Large ornate calligraphic Bismillah (`بِسْمِ ٱللَّهِ ٱلرَّحْمَٰنِ ٱلرَّحِيمِ`) in a wide, horizontally spread form. The style matches **Amiri** font with the Unicode Bismillah ligature character `﷽` (U+FDFD) which renders as a single pre-composed ornate glyph.
2. **Bottom line** — Three-part subtitle row:
   - Left: `AL WIRD AL-ASAS` in tracked uppercase Latin (small-caps feel, wide letter-spacing)
   - Center: decorative ornament — `❖` or three dots (`⁂` / `✦ ✦ ✦`)
   - Right: `الورد الأساس` in Arabic serif

The color in the image is a muted blue-grey — roughly `#4a5568` / slate-500 — matching the app's `muted-foreground` token. The `muted-foreground` CSS variable maps to `oklch(0.45 0.01 60)` in light mode, which is a warm grey. This is the right token to use since the header should recede behind the ring content.

---

## Font

### Amiri (new, needs adding)

- Available on Google Fonts: `Amiri` — classical Naskh, designed for Quranic text
- The **Bismillah ligature** `﷽` (U+FDFD) renders as the wide ornate single-glyph form in Amiri
- Load via `next/font/google` exactly as `Scheherazade_New` is already loaded in `app/layout.tsx`
- Import: `import { Amiri } from "next/font/google"`
- Config: `{ subsets: ["arabic"], weight: ["400"], variable: "--font-amiri", display: "swap" }`
- Add `${amiri.variable}` to the `<html>` className in layout

### Existing fonts for subtitle
- **Latin text** `AL WIRD AL-ASAS`: `--font-geist-mono` with `tracking-widest` and `uppercase text-[10px]`
- **Arabic text** `الورد الأساس`: `--font-arabic` (Scheherazade New, already loaded)

## Implementation — files to change

### 1. `app/layout.tsx`
- Import `Amiri` from `"next/font/google"`
- Instantiate: `const amiri = Amiri({ subsets: ["arabic"], weight: ["400"], variable: "--font-amiri", display: "swap" })`
- Add `amiri.variable` to `<html>` className string

### 2. `app/globals.css`
- Expose the CSS variable to Tailwind: add `--font-amiri: var(--font-amiri);` inside `@theme inline`

### 3. `components/counter/BismillahHeader.tsx` (new component)
A small, purely presentational Client Component (it uses `motion` for a gentle entrance animation consistent with the rest of the app):

```tsx
"use client";
import { motion } from "motion/react";

export function BismillahHeader() {
  return (
    <motion.div
      className="flex flex-col items-center gap-2 select-none pointer-events-none"
      initial={{ opacity: 0, y: -6 }}
      animate={{ opacity: 1, y: 0 }}
      transition={{ type: "spring", stiffness: 300, damping: 28, delay: 0.1 }}
    >
      {/* Bismillah ligature */}
      <p
        dir="rtl"
        lang="ar"
        className="text-muted-foreground leading-none"
        style={{
          fontFamily: "var(--font-amiri)",
          fontSize: "clamp(28px, 7vw, 40px)",
        }}
      >
        ﷽
      </p>

      {/* Subtitle row */}
      <div className="flex items-center gap-3">
        <span className="text-[9px] font-mono tracking-[0.2em] uppercase text-muted-foreground">
          AL WIRD AL-ASAS
        </span>
        <span className="text-muted-foreground/60 text-[10px]">✦</span>
        <span
          dir="rtl"
          lang="ar"
          className="text-[13px] text-muted-foreground"
          style={{ fontFamily: "var(--font-arabic)" }}
        >
          الورد الأساس
        </span>
      </div>
    </motion.div>
  );
}
```

### 4. `components/counter/DhikrCard.tsx`
- Import `BismillahHeader`
- Add it as an absolutely-positioned block above the progress ring.

The ring is currently pinned at `top: calc(40% - 130px)`. The header block sits above that. It needs about 80–90px of vertical space. Place it at `top: calc(40% - 220px)` — this puts its center roughly 90px above the ring top edge, leaving comfortable breathing room.

```tsx
{/* Bismillah header — above ring */}
<div
  className="absolute left-0 right-0 flex justify-center"
  style={{ top: "calc(40% - 222px)" }}
>
  <BismillahHeader />
</div>
```

The existing `ResetButton` is at `top: calc(40% - 182px)` — this places it *between* the bismillah header and the ring, which is slightly awkward. The reset button should move to just below the ring bottom, or inside the card in a fixed position. However, since the plan says to only change what's needed for the bismillah header and the user didn't ask to move the reset button, we should verify there's no overlap.

**Overlap analysis:**
- BismillahHeader top: `calc(40% - 222px)` → the component is ~60px tall, so its bottom is at `calc(40% - 162px)`
- ResetButton top: `calc(40% - 182px)` → 20px of overlap

**Resolution:** Move `ResetButton` down to `top: calc(40% - 150px)` — still clearly above the ring (ring starts at `calc(40% - 130px)`) with a 20px gap, and no longer overlaps the bismillah block.
