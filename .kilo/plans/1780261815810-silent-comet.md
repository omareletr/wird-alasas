# Plan: iOS Home Screen CTA above dot indicators

## Goal
Replace the existing floating `InstallPrompt` banner with an inline, elegant CTA that lives directly above the dot indicators in `DhikrDeck`. iOS-only. Dismissable. Shared localStorage key with the existing prompt. Fade + slide-up animation via `motion`.

---

## Context

### Why the existing InstallPrompt is likely invisible
- `InstallPrompt` is already rendered in `app/page.tsx:85`
- It shows as a `fixed bottom-4 inset-x-4` overlay — floats *over* the dots
- It only appears on iOS (`/iphone|ipad|ipod/i.test(navigator.userAgent)`) when NOT standalone and NOT already dismissed (`localStorage.getItem("install-prompt-dismissed")`)
- If previously dismissed in the browser, it will never show again

### Decision summary (from user answers)
- **Copy:** Short — share icon + "Add to Home Screen" text, no verbose instruction. A single unobtrusive line.
- **Replace or coexist:** The user was surprised the banner existed. We will **replace** the floating banner approach and move entirely to the inline-above-dots CTA for iOS. The existing `InstallPrompt` component will be gutted/repurposed or removed from `page.tsx`.
- **Dismiss persistence:** Shared key `"install-prompt-dismissed"` — dismiss once, never show again.
- **Animation:** Fade + slide up via `motion/react` `AnimatePresence`.

---

## Architecture

### What changes

1. **`components/counter/DhikrDeck.tsx`** — add a small iOS CTA row between the card area and the dot indicators. The CTA:
   - Reads iOS detection + standalone check + dismissed state (same logic as `InstallPrompt`)
   - Renders only when: iOS + not standalone + not dismissed
   - Wraps in `AnimatePresence` for fade+slide animation
   - Has an `X` dismiss button that sets the shared localStorage key and hides itself
   - Uses the Share icon (Lucide) inline with the text

2. **`components/InstallPrompt.tsx`** — remove from `app/page.tsx` and either:
   - Delete the file, OR
   - Keep the file but repurpose it for Android-only (`beforeinstallprompt`) — since the user said "coexist for Android later", we keep the Android path in place but remove iOS from it, and keep the component rendered in `page.tsx` for Android
   
   **Decision:** Keep `InstallPrompt` but strip iOS-specific logic from it (it currently shows on iOS regardless of `beforeinstallprompt`). The inline CTA handles iOS; `InstallPrompt` handles Android (`beforeinstallprompt` event only).

3. **No new file needed** — logic lives directly in `DhikrDeck.tsx` OR extracted to a tiny sibling `components/counter/IOSInstallCTA.tsx`. Given the component has several concerns, a small separate file is cleaner.

## Detailed implementation

### New file: `components/counter/IOSInstallCTA.tsx`

```tsx
"use client";
import { useState, useEffect } from "react";
import { motion, AnimatePresence } from "motion/react";
import { Share, X } from "lucide-react";

const STORAGE_KEY = "install-prompt-dismissed";

function isIOS() {
  return /iphone|ipad|ipod/i.test(navigator.userAgent);
}

function isStandalone() {
  return window.matchMedia("(display-mode: standalone)").matches;
}

export function IOSInstallCTA() {
  const [show, setShow] = useState(false);

  useEffect(() => {
    if (!isIOS() || isStandalone() || localStorage.getItem(STORAGE_KEY)) return;
    // Delay so the CTA doesn't compete with the initial render
    const timer = setTimeout(() => setShow(true), 1500);
    return () => clearTimeout(timer);
  }, []);

  function dismiss() {
    localStorage.setItem(STORAGE_KEY, "1");
    setShow(false);
  }

  return (
    <AnimatePresence>
      {show && (
        <motion.div
          initial={{ opacity: 0, y: 8 }}
          animate={{ opacity: 1, y: 0 }}
          exit={{ opacity: 0, y: 8 }}
          transition={{ duration: 0.35, ease: [0.4, 0, 0.2, 1] }}
          className="flex items-center justify-center gap-1.5 mb-3"
        >
          <p className="text-[10px] font-sans text-muted-foreground/60 flex items-center gap-1">
            <Share className="w-3 h-3 shrink-0" />
            Add to Home Screen
          </p>
          <button
            onClick={dismiss}
            aria-label="Dismiss"
            className="text-muted-foreground/40 hover:text-muted-foreground/70 transition-colors"
          >
            <X className="w-3 h-3" />
          </button>
        </motion.div>
      )}
    </AnimatePresence>
  );
}
```

**Design notes:**
- `text-[10px]` — matches the app's micro-typography scale
- `text-muted-foreground/60` — intentionally dim; a nudge, not a shout
- Share icon is inline with text, no separate instruction line (user chose "shorter")
- `mb-3` spacing separates it cleanly from the dots without eating too much vertical room
- No border/card background — floats cleanly above dots, stays minimal
