# Fix: Ring at Consistent Y Using Absolute Positioning

## Root Cause of Current Regression

`padding-top` percentage in CSS is relative to the **containing block's WIDTH**, not its height.
`pt-[15%]` on a 375px-wide card = ~56px of top padding on every device, regardless of card height.
On a 730px-tall phone, the ring center ends up at ~186px from top (only 25% down), leaving a huge empty void below the text — the "pushed up" appearance.

## Root Cause of Original Bug

`justify-center` centers the entire block (ring + gap + text) as a unit.
Different text lengths → different total block heights → ring center shifts by ~25px between cards.

---

## Fix: Absolute Positioning for the Ring

For an **absolutely positioned** element, `top: X%` is relative to the containing block's **height** — exactly what we need.

### Strategy

1. Make the outer div `relative h-full w-full` (remove flex, remove padding)
2. Position the ring `absolute` at `top: calc(40% - 130px)` — ring center always at **40% of card height**, identical for every card on the same device
3. Position the text block `absolute` at `top: calc(40% + 162px)` — always exactly 32px (mt-8) below the ring bottom, regardless of screen size

### Why 40%?

The original `justify-center` placed the ring center at ~38–43% of card height (varying with text length — that was the bug). Targeting 40% matches the original visual feel while making the position constant.

Sanity check:
| Screen | Card height | Ring top | Ring center | Text starts |
|--------|-------------|----------|-------------|-------------|
| iPhone SE (375×667) | ~545 px | 88 px | 218 px (40%) | 380 px |
| iPhone 14 Pro (393×852) | ~730 px | 162 px | 292 px (40%) | 454 px |
| Large Android (412×915) | ~793 px | 187 px | 317 px (40%) | 479 px |

Longest text block (Salawat, ~110px): fits in remaining space on all screens above. ✓

## Implementation

### Outer div (line 28)

**Before:**
```tsx
<div className="flex flex-col items-center h-full w-full px-8 select-none pt-[15%]">
```

**After:**
```tsx
<div className="relative h-full w-full select-none">
```

### Ring group (lines 30–46)

Wrap in an absolutely-positioned centering shell:

**Before:**
```tsx
<div className="relative flex items-center justify-center">
  <ProgressRing ... />
  <div className="absolute flex flex-col items-center gap-1">
    ...
  </div>
</div>
```

**After:**
```tsx
<div
  className="absolute left-1/2 -translate-x-1/2"
  style={{ top: 'calc(40% - 130px)' }}
>
  <div className="relative flex items-center justify-center">
    <ProgressRing ... />
    <div className="absolute flex flex-col items-center gap-1">
      ...
    </div>
  </div>
</div>
```

### Text block (lines 49–69)

**Before:**
```tsx
<div className="flex flex-col items-center gap-6 w-full mt-8">
  ...
</div>
```

**After:**
```tsx
<div
  className="absolute left-0 right-0 flex flex-col items-center gap-6 px-8"
  style={{ top: 'calc(40% + 162px)' }}
>
  ...
</div>
```

The calc breakdown: `40% + 130px (ring half-height) + 32px (gap, mt-8 equivalent) = 40% + 162px`

### Inner content of ring and all three `<p>` tags: **unchanged**

## Notes

- `left-1/2 -translate-x-1/2` centers the ring horizontally (same as before via `items-center` on the flex parent)
- The outer div no longer needs `flex` since both children are absolutely positioned
- `px-8` moves from the outer div to the text wrapper (the ring is centered via `left-1/2` so it doesn't need horizontal padding)
- `overflow-hidden` is already on the parent `DhikrDeck` — no change needed
- No changes to `DhikrDeck.tsx`, `page.tsx`, or any other file
