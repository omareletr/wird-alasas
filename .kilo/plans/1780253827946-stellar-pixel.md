# Plan: Subtle Ring Completion Animation

## Problem

The current completion animation in `ProgressRing.tsx` is too "loud":

1. **Scale overshoot** — `scale: 1.18` causes the pulse circle to visibly expand outward beyond the ring track, which is jarring.
2. **High initial opacity** — starts at `opacity: 0.65`, making it immediately prominent.
3. **Hard green color** — `#22c55e` is a bright, saturated green that pops strongly against both the warm light theme and the dark theme.
4. **Short duration** — 0.55 s feels snappy/abrupt rather than graceful.

## Current animation (ProgressRing.tsx:56–71)

```tsx
<motion.circle
  key="complete-pulse"
  initial={{ opacity: 0.65, scale: 1 }}
  animate={{ opacity: 0, scale: 1.18 }}
  transition={{ duration: 0.55, ease: "easeOut" }}
/>
```

## Proposed changes

### 1. Tone down the pulse circle (`ProgressRing.tsx`)

| Property | Before | After | Rationale |
|---|---|---|---|
| `initial opacity` | 0.65 | 0.35 | Less "flash" at the moment of completion |
| `animate scale` | 1.18 | 1.06 | Barely perceptible size change — more of a shimmer |
| `duration` | 0.55 s | 0.8 s | Slower fade reads as elegant rather than urgent |
| `ease` | `"easeOut"` | `[0.4, 0, 0.2, 1]` (material ease-in-out) | Smooth, unhurried feel |
| `stroke color` | `#22c55e` | `var(--accent)` | Use the theme accent instead of hard green for a cohesive glow |
| `strokeWidth` | same as ring (4) | `strokeWidth - 1` (3) | Slightly thinner glow circle feels lighter |

The completed ring stroke color (`stroke={completed ? "#22c55e" : "var(--accent)"}`) will also change to `var(--accent)` so the entire completion state uses the theme palette rather than a hard-coded green.

### 2. No change to `CompletionOverlay.tsx`

The overlay (`تَقَبَّلَ اللَّهُ`) is a separate layer and is not part of the ring pulse — it is already subtle.

### 3. No change to `DhikrCard.tsx`

The pulse trigger logic (fires once on completion, clears after 700 ms) is correct and stays as-is.
