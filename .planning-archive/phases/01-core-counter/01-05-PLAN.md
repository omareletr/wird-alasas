**Step A — Create components/counter/CompletionOverlay.tsx:**

A full-screen overlay that fades in over the counter. Design: pure black background (80% opacity), centered Arabic phrase and English subtitle. Gentle fade-in via `motion.div`. Tap anywhere to dismiss.

Design decisions (Claude's discretion per research open question #2):
- Background: `bg-black/80` (80% black) — lets the counter show faintly through
- Arabic text: "تَقَبَّلَ اللَّهُ" (with harakat) — "May Allah accept [it]"
- English subtitle: "May Allah accept"
- Font: `--font-arabic` CSS variable (Noto Naskh Arabic), same as DhikrCard
- Animation: fade in opacity 0 → 1 over 400ms, no scale/bounce
- Dismiss: tap anywhere on the overlay
- No auto-dismiss timer — the moment is for the user to sit with

```typescript
"use client";
import { motion } from "motion/react";

interface CompletionOverlayProps {
  onDismiss: () => void;
}

export function CompletionOverlay({ onDismiss }: CompletionOverlayProps) {
  return (
    <motion.div
      initial={{ opacity: 0 }}
      animate={{ opacity: 1 }}
      transition={{ duration: 0.4, ease: "easeIn" }}
      onClick={onDismiss}
      className="absolute inset-0 z-50 flex flex-col items-center justify-center bg-black/80 cursor-pointer"
    >
      <div className="flex flex-col items-center gap-4 px-8 text-center">
        <p
          dir="rtl"
          lang="ar"
          className="text-4xl text-white/90"
          style={{ fontFamily: "var(--font-arabic)", lineHeight: 2 }}
        >
          تَقَبَّلَ اللَّهُ
        </p>
        <p className="text-sm text-white/50 tracking-wider uppercase">
          May Allah accept
        </p>
      </div>
    </motion.div>
  );
}
```

**Step B — Wire completion detection into app/page.tsx:**

Completion is: `ADHKAR.every((entry) => counts[entry.index] >= getTarget(entry, mode))`.

Add a `dismissed` local state so the overlay doesn't reappear while the session is still active:

```typescript
// In CounterPage:
import { useState } from "react";
import { ADHKAR, getTarget } from "@/lib/data/adhkar";
import { CompletionOverlay } from "@/components/counter/CompletionOverlay";

// Inside component:
const { counts, mode } = useSessionStore();
const [overlayDismissed, setOverlayDismissed] = useState(false);

const allComplete = ADHKAR.every(
  (entry) => counts[entry.index] >= getTarget(entry, mode)
);
const showOverlay = allComplete && !overlayDismissed;

// In return JSX, wrap the main div in relative positioning and add the overlay:
return (
  <main className="relative flex flex-col h-dvh w-full bg-black overflow-hidden">
    <div className="flex items-center justify-between px-4 pt-4 shrink-0">
      <ModeToggle />
      <SettingsSheet />
    </div>
    <div className="flex-1 min-h-0">
      <DhikrDeck />
    </div>
    {showOverlay && <CompletionOverlay onDismiss={() => setOverlayDismissed(true)} />}
  </main>
);
```

**Important:** `overlayDismissed` resets to `false` if the session resets (counts go back to 0 after a new session starts). This is automatic — `allComplete` will be false after reset, so `showOverlay` becomes false even if `overlayDismissed` stays true.

**`relative` positioning** is added to `<main>` so that `CompletionOverlay`'s `absolute inset-0` is constrained to the page, not the viewport.
